# Versun — счётчик здоровья

Питание, траты, тренировки и ИИ-помощник. Один сайт без сервера.

## Как выложить на GitHub Pages
1. Создайте репозиторий и загрузите ВСЕ файлы из этой папки в корень (включая `.nojekyll`).
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.
4. Телефон: откройте ссылку → «Поделиться» → «На экран Домой» (iPhone) или «Установить приложение» (Android).

## ИИ
Вставьте API-ключ в Профиле. В код ключ вписывать нельзя — на GitHub Pages он станет публичным.

## Безопасность
- Данные каждого пользователя шифруются его паролем (AES-256-GCM, ключ из PBKDF2-SHA256, 600 000 итераций) и лежат только в браузере. В репозитории и на сервере их нет.
- Пароль восстановить нельзя. Забыли — данные не открыть.
- Защита от подбора: пауза после 3 неверных паролей. Автовыход через 5 минут без действий.
- Политика CSP ограничивает, куда страница может отправлять запросы (только https).
- Имена пользователей хранятся открыто, сами данные — нет.
- Ограничение: аккаунты привязаны к устройству. Для входа с разных устройств нужен сервер (например Supabase).
